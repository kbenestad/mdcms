# About this showcase

This is a reference MD-CMS site. Everything you see is produced from markdown
files, a `config.yml`, and a `theme.yml`, rendered entirely in the browser by
`index.html`. There is no build step and no server.

## Structure

```
showcase/
  index.html      renderer
  config.yml      site identity + navigation
  theme.yml       colours, fonts, layout
  nav.yml         generated by `mdcms build`
  search.json     generated by `mdcms build`
  pages/          markdown pages
  posts/          markdown posts
  assets/         icons and images
```

## Regenerate

Run `mdcms build --path sample-sites/showcase` to rebuild `nav.yml`,
`search.json`, and the site manifest after editing content.

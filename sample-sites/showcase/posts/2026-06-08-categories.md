# One site, many languages

`categories-use: yes` turns on a language (or audience) switcher. Each page
can have a variant per category using a filename suffix — `about.nb.md` is
the Norwegian variant of `about.md`. No suffix means the default category.
This showcase now runs both: try the switcher in the top bar and visit
*Home* or *Language switcher* in Norsk. See the *Language switcher* guide
for the exact `config.yml` block.
